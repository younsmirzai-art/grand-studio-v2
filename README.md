# Grand Studio

The universal 3D model hub. Download 3D models from every marketplace in one place, powered by AI curation.

## Features

- 🎨 Browse 500K+ models from Poly Haven, Sketchfab, and more
- 🔍 AI-powered search and recommendations
- 📥 Free tier: 10 downloads/day
- 💎 Pro tier: $4.99/month unlimited
- 🎮 Companion UE5 plugin available on Fab Marketplace

## Tech Stack

- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Supabase (Auth + Database)
- Stripe (Payments)
- Vercel (Hosting)

## Development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and fill in values.
